# PARS CHAT — چت پارس

پیام‌رسان اندرویدی فارسی با Kotlin و Jetpack Compose؛ هویت بصری آن از هنر ایران باستان الهام گرفته شده و از نشان اختصاصی فروهر و حباب گفتگو، لاجوردی تیره، طلایی و فیروزه‌ای استفاده می‌کند.

## مشخصات
- نام نمایشی: چت پارس
- سازنده: بنیامین نوری دفرازی
- Android applicationId: `com.bentech.parschaatt`
- Kotlin namespace: `com.bentech.parschat`
- حداقل Android: 7.0 / API 24
- Compile SDK: 35
- Target SDK: 34
- زبان رابط: فارسی، با چیدمان راست‌به‌چپ سراسری

## قابلیت‌های پیاده‌سازی‌شده در سورس
1. ثبت‌نام و ورود با Firebase Authentication (ایمیل/گذرواژه)
2. نمایه کاربر و بارگذاری تصویر پروفایل
3. فهرست و جستجوی زنده کاربران
4. گفتگوی خصوصی بلادرنگ با Cloud Firestore
5. وضعیت آنلاین و آفلاین
6. آخرین بازدید و تنظیمات حریم خصوصی
7. رسید خوانده‌شدن پیام
8. ویرایش و حذف نرم پیام
9. پاسخ به پیام و فوروارد متنی
10. ارسال و نمایش تصویر
11. ضبط، ارسال و پخش پیام صوتی
12. ایجاد و مدیریت گروه‌ها
13. اعلان پیام با Firebase Cloud Messaging و Cloud Functions
14. مسدودسازی و رفع مسدودسازی کاربران
15. پنل مدیریت مبتنی بر custom claims و توابع سمت سرور

## ساخت APK
ساخت APK در GitHub Actions عمداً دستی است. پس از تأیید رابط و آماده‌شدن سرویس‌های Firebase:
1. وارد زبانه **Actions** مخزن شوید.
2. گردش‌کار **Build PARS CHAT APK** را انتخاب کنید.
3. روی **Run workflow** بزنید.
4. پس از پایان موفق، Artifact با نام `PARS-CHAT-debug-apk` را دریافت کنید.

این مخزن هنوز نباید به‌عنوان نسخه آزمایش‌شده یا آماده انتشار عمومی تلقی شود؛ تا زمان ثبت یک اجرای موفق Build و آزمون روی دستگاه، سازگاری نهایی تأیید نشده است.

## راه‌اندازی Firebase
پروژه موجود Firebase با شناسه `parschat-3f91f` و ثبت فعلی Android استفاده می‌شود. ثبت اپ جدید لازم نیست. فایل `google-services.json` در زمان اجرای workflow از Secret با نام `GOOGLE_SERVICES_JSON` وارد محیط Build می‌شود.

راهنمای کامل انتشار قوانین Firestore، قوانین Storage و Cloud Functions در [docs/FIREBASE_DEPLOYMENT.md](docs/FIREBASE_DEPLOYMENT.md) است. این سرویس‌ها تا زمانی که در پروژه Firebase مستقر نشوند، فعال نیستند.

## وضعیت و محدودیت‌ها
- کد کلاینت، قوانین و توابع سرور در مخزن قرار دارند؛ اما هنوز کامپایل رسمی و آزمون روی دستگاه ثبت نشده است.
- قوانین Firebase و Cloud Functions باید روی پروژه موجود Deploy و با دو حساب عادی و یک مدیر آزمایش شوند.
- وضعیت آنلاین ممکن است پس از توقف اجباری برنامه مدتی کهنه بماند.
- فوروارد در نسخه فعلی فقط متن را پشتیبانی می‌کند.
- برای مقیاس بالاتر، صفحه‌بندی پیام‌ها و پایش عملیاتی لازم است.

## امنیت
هرگز فایل service-account، کلید خصوصی یا مقادیر محرمانه Firebase را در مخزن عمومی Commit نکنید. Secret مربوط به Build را در GitHub Actions نگه دارید.
