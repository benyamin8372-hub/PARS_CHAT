# PARS CHAT

اپلیکیشن اندرویدی نمایشی با Kotlin 2.0 و Jetpack Compose، الهام‌گرفته از هنر ایران باستان.

- سازنده: بنیامین نوری دفرازی
- شناسه برنامه: `com.bentech.parschat`
- حداقل نسخه: Android 7 / API 24
- Target SDK: 34
- نسخه: 1.0.0

## قابلیت‌های این نسخه
- صفحه آغاز، معرفی و ورود نمایشی
- فهرست ۸ گفتگوی نمونه
- گفتگو و ارسال پیام محلی در حافظه
- تماس تصویری نمایشی (بدون WebRTC و اتصال واقعی)
- تنظیم حالت تاریک و نمایه کاربر

## دریافت APK
پس از هر Push به شاخه `main`، GitHub Actions تلاش می‌کند APK دیباگ بسازد. از تب Actions آخرین اجرای موفق را باز کرده و Artifact با نام `PARS-CHAT-debug-apk` را دانلود کنید.

این نسخه هنوز به سرور، احراز هویت واقعی یا ارسال پیام اینترنتی متصل نیست.
